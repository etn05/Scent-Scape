# Scense — 3JS Scent Scape

A 3D interactive scent space built with Three.js for **Hybrid Visual Identity / Brand Development**.

This project explores how scent can be experienced digitally through visual interaction. Instead of smelling a fragrance physically, users navigate a virtual environment where scents are represented through 3D objects, atmosphere, color, texture, and movement.

## Concept

**Scense** is a speculative scent brand that reimagines fragrance as something immersive, spatial, and interactive.

The **Scent Scape** acts as a digital extension of the brand identity. Users can hover over different 3D objects to reveal scent notes, moods, or associations, turning fragrance discovery into a visual and exploratory experience.

## Features

* Interactive 3D environment built in Three.js
* Hover-based scent discovery
* 3D objects representing different scent profiles
* Visual atmosphere designed to communicate scent, mood, and brand feeling
* Digital-first approach to fragrance exploration
* Experimental brand experience for a hybrid visual identity system

## Project Purpose

This project was created to support the brand development of **Scense**, focusing on how a scent brand can exist beyond packaging or physical retail.

It asks:

How can scent be translated into a digital space?

How can users “explore” fragrance visually?

How can interaction, motion, and atmosphere become part of a brand identity?

## Tech Stack

* Three.js
* JavaScript
* HTML
* CSS

## How to Use

Hover over the 3D objects in the scene to explore different scent elements and visual associations.

Each object represents a different part of the scent experience, creating a more playful and immersive way to engage with fragrance.
